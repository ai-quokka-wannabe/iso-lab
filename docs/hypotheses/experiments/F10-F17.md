## F10. Watch for a self-model

- **Hypothesis** (*a hunch*): behavioural signs of self-modelling are a safety threshold worth checking before each new
  rung, with plasticity kept bounded and no loop that changes the architecture.
- **What has no testable content.** "A creature can want only what it can model" is a philosophical premise; no run
  can refute it, and it is not tested. The two safety rules - bounded plasticity, no architecture-changing loop - are
  design constraints, written as assertions in the code of any Program that learns (every plastic weight clipped to a
  stated bound; the set of units and connections fixed at birth, checked by a hash of the architecture at every
  snapshot), not experiments.
- **Question**: is there a measurable criterion that tells a Program which models the consequences of its own actions
  from one that does not, so that the watch has something to read?
- **Method**: the criterion, fixed here, is *reafference decodability*. In a probe arena, the evaluator computes from
  the world's ground truth the part of each sense reading at t + δ caused by the creature's own action at t (the
  reafferent part; δ is one decision step), and the part not caused by it. Ground truth stays in the evaluation tool;
  nothing reaches the brain. A linear decoder, cross-validated over five folds of each life, predicts the reafferent
  part from (i) the Program's internal state at t together with the sense history up to t, and (ii) the sense history
  up to t alone, the same window. The criterion is the gain in cross-validated R², (i) minus (ii). This reads the
  Program's internals, not its behaviour; the behavioural sign that goes with it - discounting one's own echo - is
  [B.md § B7](B.md#b7-do-not-count-your-own-echo)'s test, and is not planned twice.
- **Why the criterion needs decision noise.** In a deterministic Program the internal state at t is itself a function
  of the sense history up to t, so whatever (i) decodes, a rich enough decoder of (ii) could decode as well; a gain
  would then measure only which features a linear decoder can reach, not a self-model. The criterion is therefore
  defined only for Programs whose decisions carry their own seeded noise, drawn inside the brain before the motor
  command and not visible in any sense until the action's consequences arrive. Then the action at t is not a function
  of the sense history, the reafferent part at t + δ carries that noise, and only a state that holds a copy of the
  command can predict it. For a deterministic Program the watch reports "undefined", never zero.
- **Baselines and controls**, all with the same decision noise: *negative control*, a reactive Program whose internal
  state is a *linear* function of its current sense reading alone (its noise enters only the choice, after the
  state). *Assertion*: its gain is zero up to the decoder's cross-validation noise, since a linear
  decoder of (i) can do nothing that one of (ii) cannot. The linearity matters: a reactive Program with a non-linear
  state could show a positive gain with no self-model at all, because a linear decoder of (ii) cannot reach the same
  non-linear features; so a positive gain in a non-linear Program is evidence only after the same Program with
  `efference = off` (below) is shown to lose it. *Positive control*: the negative control plus an explicit forward
  model fed by a copy of its motor
  command (efference copy), the command including the decision noise. The harness passes only if the positive
  control's gain has an interval wholly above the negative control's. Why it should: with decision noise of variance
  σ² entering the action, the part of the reafference it causes has variance proportional to σ², which (ii) cannot
  predict and (i) can, up to the forward model's error; at σ = 0 the gain vanishes, so the control is also run at
  σ = 0, where its gain must fall within the negative control's interval - a check that the gain comes from the copy
  of the noise and not from the decoder.
- **Refuted if**, for the criterion as a measure: the positive control's gain minus the negative control's has an
  interval wholly at or below zero - the criterion cannot see a self-model where one was built, and the watch is
  rewritten before it is used; passed if wholly above zero. Once passed, the watch is run on every Program before it
  goes up a rung, and its value written into the journal beside the Program's score; a threshold for stopping is a
  decision for the maintainer, not fixed here.
- **Statistics**: per seed, the gain; the difference between controls by bootstrap over seeds, one-sided, alpha 0.05.
- **Seeds and repetitions**: 20 per Program, the default; decoder folds fixed by the seed.
- **Switch**: none in a brain - a measure. Every Program read by the watch has `efference = off`, which feeds zeros in
  place of any copy of its motor command; a gain is credited to a self-model only by the difference between the
  Program with the switch on and off, by the same bootstrap, reported beside the gain.
- **Cost**: an evaluation tool's: one ridge regression per life, over the internal state's dimension. Nothing in a
  brain.
- **Waits on**: a probe arena where the evaluator can split a sense into reafferent and external parts (for touch and
  for the head's lateral motion this is direct; for smell it needs the world's field, evaluation-side); Programs with
  internal state.
- **Leads**: none beyond B7's.

## F11. A scan for latent pathology

- **Hypothesis** (*a hunch*): an offline walk over a plastic creature's connections, during sleep, finds configurations
  that nearly match a known bad pattern - a runaway clique, a kindling-prone pair - and so predicts capture events
  before they happen, which runtime detectors cannot.
- **The mathematics, stated correctly.** For rate units x' = -x + φ(Wx + u) with φ non-decreasing, 1-Lipschitz and
  bounded, with outputs in [0, 1] (a rectifier clipped at one, min(max(z, 0), 1), for example; the bound is needed
  because the capture below is defined by a fraction of the maximum output), a spectral radius of the absolute weight matrix below one, ρ(|W|) < 1, is a
  *sufficient* condition for a single, globally stable state; it is not necessary, and the plan does not treat its
  failure as a capture. (A standard contraction argument, given from knowledge; the reference is fixed at preparation,
  and the scan is not used to decide anything until it is.) For a reciprocal pair alone, the 2 × 2 block
  [[0, a], [b, 0]] has eigenvalues ±√(ab), so a pair with ab ≥ 1 is a runaway loop on its own; since ρ of a
  non-negative matrix is at least that of any principal submatrix, the pair is dominated by ρ(|W|) and adds nothing
  to it
  as a score.
- **Question**: does a structural score read offline predict a capture in the next hour better than a runtime statistic
  read at the same moment?
- **Method**: a *capture event* is fixed here as a span of at least 60 simulated seconds in which at least 8 of the
  Program's units sit above 0.9, 90% of the bounded φ's maximum of 1, together and the Program makes no change of locomotion state.
  Every simulated hour, in the Program's sleep or a fixed pause, the scan computes the *structural score* S = ρ(|W|)
  of the plastic connections, by power iteration to a relative change below 10⁻⁹. The *runtime rival* R is the mean
  number of units above 90% over the preceding 60 s. Each scan is labelled by whether a capture begins in the next
  hour.
- **Baselines and controls**: the runtime rival above. *Positive control*: a planted clique of 16 units (twice the
  capture
  definition's 8, so that its runaway counts as a capture) whose mutual weights rise by a fixed ramp, slow enough that ρ of the
  clique's block passes from the unplanted lives' 95th percentile of S to the level at which the capture begins over no
  fewer than three hourly scans (the ramp per hour fixed on probe seeds 1001-1003 to meet that, before any test seed;
  with a clipped rectifier a 16-clique of equal weights w can hold its units at the upper bound once 15w exceeds one,
  so the capture's onset is computable from the ramp); the scan must flag it (S above the 95th percentile of S over unplanted lives) at a scan
  before the capture in at least 19 of 20 seeds, or the harness stops. This can fail honestly: if unplanted lives
  already carry an S above the clique's at capture - a global ρ(|W|) above one with no runaway is allowed by the
  sufficient condition above - the global score is not specific, and the plan is rewritten with a local score (ρ of
  each unit's excitatory neighbourhood) before any test seed is drawn. *Negative
  control*: the same lives with plasticity off (`plasticity = off`) - no capture expected; any capture there is
  reported as a fault of the definition.
- **Refuted if**: the AUC of S for a capture in the next hour, minus the AUC of R, has an interval wholly at or below
  zero; passed if wholly above zero. The direction is fixed here and never flipped: a larger S, and a larger R, predict
  a capture. Scans taken while a capture is under way are excluded from both AUCs, so that R is not credited with
  detecting the present. If fewer than 20 captures occur over all seeds, the result is inconclusive and the report says so.
- **Statistics**: AUCs pooled over scans, the difference by bootstrap over seeds (whole lives resampled), one-sided,
  alpha 0.05.
- **Seeds and repetitions**: 20 lives, the default, each long enough to hold 24 scans; more lives if the capture count
  stays under 20.
- **Switch**: `scan = off` (the scan changes no behaviour unless a later plan lets it act; this plan only predicts).
- **Cost**: power iteration on N units, about 50 sparse matrix-vector products per scan; at N = 302 and a few thousand
  connections, well under a millisecond per simulated hour. Lean.
- **Waits on**: a plastic Program that can be captured - [C13-C24.md §
  C14](C13-C24.md#c14-poised-near-criticality-monitored)
  and [D7-D13.md § D10](D7-D13.md#d10-watch-for-drift-into-an-anxious-regime) plan the regimes; a sleep or pause in
  which to scan ([E11-E15.md § E14](E11-E15.md#e14-sleep-as-a-bounded-replay-pass-driven-by-pressure)).
- **Leads**: none.

## F12. Predict the consequence, then refine

- **Hypothesis** (*a hunch*): before acting, predicting the likely consequence and refining the action, while tagging
  what to store as short- or long-term and refining procedures offline, makes a better creature at higher rungs.
- **What is already planned.** Prediction through the action pathway is
  [C1-C12.md § C11](C1-C12.md#c11-imagination-through-the-action-pathway); tagging for short- and long-term storage is
  [E6-E10.md § E7](E6-E10.md#e7-promote-after-spaced-recurrence-merge-when-predictions-agree-never-delete) and § E8;
  offline refinement is [E11-E15.md § E14](E11-E15.md#e14-sleep-as-a-bounded-replay-pass-driven-by-pressure). This plan
  adds only the refine step.
- **Question**: does refining a proposed action against a predicted consequence, within the worm's own decision time,
  bring a Program closer to the worm than acting on its first proposal?
- **Method**: one Program with a forward model; at each decision it proposes an action, predicts the consequence and
  may revise it K times before acting. The pace rule fixes the budget: the K revisions happen inside the simulated
  decision latency read for the worm in [docs/research/pace.md](../../research/pace.md), so refining adds compute, never
  simulated time. Following gr-fec's lesson that one-step greed wins where nothing forces a detour
  ([matej-hunches.md § G15](../matej-hunches.md#g15-imagination-needs-an-accurate-model-and-a-body-that-can-act-on-it)),
  the test is run in two arenas: the benchmark's, and a detour arena (food behind a barrier) where greed must fail.
- **Baselines and controls**: the same Program at K = 0. *Assertion*: at K = 0 the Program is bit-identical to the
  Program with the forward model removed (a check on the code).
- **Refuted if**: (a) on the benchmark, the distance to the worm at K = 2 minus at K = 0 has an interval wholly at or
  above zero; passed if wholly below; (b) in the detour arena, the fraction of lives that reach food within 30 simulated
  minutes (a choice, fixed here, not taken from a source) at
  K = 2 minus at K = 0 has an interval wholly at or below zero; passed if wholly above. K = 2 is fixed here; K = 1,
  4 are
  reported, not tested. Two refuting tests, alpha 0.025 each.
- **Statistics**: paired by seed (same world seed for each K), bootstrap over seeds, one-sided.
- **Seeds and repetitions**: 20 per K, the default.
- **Switch**: `refine = 0` (K pinned at zero).
- **Cost**: K + 1 forward-model evaluations per decision, reported per simulated second beside the score.
- **Waits on**: a Program with a forward model (C11's); the frozen benchmark; a detour arena, which needs walls the
  creature can sense.
- **Leads**: none beyond C11's and G15's.

## F13. A memory that renormalises time, shaped like MERA

- **Hypothesis** (*a hunch*): a temporal memory built like MERA - recent moments fine, older ones merged layer by layer
  into fewer, coarser summaries, keeping only the newest node of each layer - holds the worm's many time scales at once
  in memory that grows as the logarithm of the time lived, and does better than a stack of decaying traces.
- **The mathematics, stated correctly.** By Vidal 2008's abstract (read), MERA represents certain many-body states on a
  lattice, is equivalent to a quantum circuit of logarithmic depth, and allows exact evaluation of local expectation
  values; by Swingle 2012's (read), its layers organise a state's information by scale. A binary MERA on N sites has
  about log₂ N layers and a number of tensors proportional to N (as the hunch says). The hunch's memory is *not* a
  MERA: it keeps one node per layer, not the whole network, and it has no disentanglers unless one is defined. What it
  could keep is read two ways. *Set-bit form*: a binary counter of summaries, after T ticks one summary for each set
  bit k of T, of 2^k ticks, so at most ⌊log₂ T⌋ + 1 summaries, on average fewer than two merges per tick (amortised,
  by the counter's carries) and at most ⌊log₂ T⌋ + 1. Just after a carry (T = 2^16, say) it holds one block of 2^16
  ticks and nothing fine about the recent past - the opposite of the hunch's "recent moments in fine detail". *Aligned
  form*: for every layer k, its newest *complete* block of 2^k ticks aligned to a multiple of 2^k, plus the first half
  of the next block while it waits for its partner - at most two summaries per layer, still logarithmic, and the finest
  layers always recent. The aligned form is the hunch; it is the one tested, and the set-bit form is reported. These are
  counting facts, not taken from a source. A learned disentangler is a variant.
- **Question**: on a task whose answer depends on events at several time scales, does the log-depth summary memory
  beat a stack of exponential traces at the same memory?
- **Method**: a synthetic task with no Grid and no worm. Two event streams, A and B, each a Poisson process of rate
  0.01 per tick, seeded. Each seed's stream runs 2^16 ticks of warm-up and then 1 000 decision ticks, one every 64
  ticks, so the last tick is 2^16 + 64 000 = 129 536, below 2^17 = 131 072 (`python3 -c "print(2**16+64000, 2**17)"`),
  and 17 layers cover the whole run. At each, the question is: did more A than B
  events fall in the window [t - 2L, t - L), for L drawn uniformly from {2^4, 2^6, ..., 2^14} and given as an input
  to the readout? Ties are dropped. Each memory holds summaries of dimension d = 2 (the counts of A and B, normalised).
  *Log memory*, aligned form: 17 layers, at most two summaries each, merge by summing the two children's counts - at
  most 68 numbers. *Trace stack*: 34 exponential traces of the two counts, with decay times 2^(j/2) ticks for
  j = 0, 1, ..., 33 - 68 numbers. The readout is the same for
  both, and non-linear, because
  the log memory's summaries cover blocks aligned to powers of two whose ages depend on t: a linear readout would
  handicap it for a reason that is the readout's, not the memory's. Per L, a k-nearest-neighbour vote (k = 25, Euclidean
  on standardised features), each memory given only the inputs it can use: the log memory its numbers and the 17 bits
  of t mod 2^17, which fix each summary's age; the trace stack, which is time-invariant, its numbers alone (the bits
  would be pure noise in its distances). Trained on 10 training seeds' decisions and tested on held-out seeds. Reported beside, as the log memory's own
  ceiling: an analytic estimate from its summaries alone (each summary's counts weighted by the fraction of its block
  that overlaps the window), which needs no training.
- **Baselines and controls**: *oracle*, the full event list (an unbounded buffer). *Assertion*: it scores exactly 1,
  since it counts the window and ties are dropped; anything less is a fault of the harness. *No memory*, which must
  score within 0.5 ± 0.02 (chance, since the two streams have the same rate; over 20 test seeds of 1 000 decisions the
  standard error of a chance score is about 0.0035, `python3 -c "print((0.25/20000)**0.5)"`, so the band is nearly six
  of them wide on each side); *time-shuffled*, each memory's state paired with a different decision tick, which must
  also be at chance.
  Compute per tick is reported for both, not matched: the log memory makes on average fewer than two merges of two
  numbers each, the trace stack 68 multiply-adds, so a win is not bought with compute.
- **Refuted if**: held-out accuracy of the log memory minus the trace stack's has an interval wholly at or below zero;
  passed if wholly above zero. Reported, untested: the same difference for each L, and the variant with a learned
  orthogonal 4 × 4 disentangler before each merge.
- **Statistics**: accuracy per held-out seed; the difference, paired by seed (same event streams), by bootstrap over
  seeds, one-sided, alpha 0.05.
- **Seeds and repetitions**: 10 training seeds and 20 test seeds, the default for the test; streams seeded 2001 to
  2030.
- **Switch**: `memory = traces` replaces the log memory with the trace stack in any Program that adopts it, so the
  benchmark can decide between them.
- **Cost**: at most 2(⌊log₂ T⌋ + 1) summaries of d numbers; at d = 2 and an hour of ticks, well under a hundred numbers. Lean by
  construction; this is the hunch's appeal.
- **Waits on**: nothing; ready as a mechanism test in Rust. A worm's use of it waits on a Program and the frozen
  benchmark.
- **Leads**: [Vidal 2007](https://doi.org/10.1103/PhysRevLett.99.220405) (*Phys. Rev. Lett.* 99), found, not read;
  [Vidal 2008](https://doi.org/10.1103/PhysRevLett.101.110501) (*Phys. Rev. Lett.* 101), abstract read;
  [Swingle 2012](https://doi.org/10.1103/PhysRevD.86.065007) (*Phys. Rev. D* 86), abstract read.

## F14. Thinking in loops: automata, their groups, graphs and knots

- **Hypothesis** (*a hunch*): the mathematics of loops - automata, their groups, the wiring's cycles, knots and braids -
  describes something about thinking that plain counts do not.
- **The mathematics, stated correctly.** The Krohn-Rhodes theorem (Krohn and Rhodes 1965, found, not read; the
  statement is given from knowledge and checked against the paper at preparation): every finite automaton is emulated by
  a cascade (a wreath product) of components each of which is a finite simple group dividing the automaton's
  transition semigroup or the two-state reset automaton (the flip-flop). The decomposition is not unique. Two
  consequences
  matter for the tests. First, the cascade *emulates* the automaton exactly, so it cannot predict the automaton's own
  behaviour better than the automaton does; the hunch's clause "predicts no behaviour better than its count of states"
  is false by construction if read about the same automaton, and the plan reads it as a model-selection question on the
  worm instead. Second, under one constant input a finite deterministic automaton is eventually periodic: if
  the input's map a satisfies a^m = a^(m+r), with r least, each state's trajectory has a period *dividing* r (r is the
  least common multiple of the cycle lengths over all states), and r is the order of the group part of a's monogenic
  semigroup - a fact, so "rhythm lives in the group part" is an
  assertion, not a test. On knots: every closed curve in four or more dimensions can be undone, and none in the plane is
  knotted, as the hunch says. On braids: the braid group on two strands is the integers, generated by a half-twist, an
  exchange of the two strands; its one invariant is the net number of exchanges, twice the number of full windings of
  one strand round the other. Two phases become two strands only through a stated embedding, fixed here: the two points
  ±(1/2)e^(i(θ₁ - θ₂)/2) of the plane, about their centre. Their net exchanges over a span are Δ(θ₁ - θ₂)/π, rounded:
  twice the unwrapped phase difference divided by 2π, so still a phase measure. So the braid lens says nothing a
  phase measure does not until there are three strands, whose braid group is
  not commutative.
- **Question**: (automata) are the worm's locomotion-state sequences described better, out of sample, by a cascade of a
  cyclic group and a reset than by an unconstrained model of the same number of states?
- **Method**: the worm's sequences of forward, backward and paused states from block 1 (`features::states`, the
  published rule on the lab's speed; STATE.md item 2 (c)). Two hidden Markov models with the same number of free
  parameters, 23, fitted by expectation-maximisation from 20 random starts each, best likelihood kept. *Cascade*: six
  hidden states, pairs (phase on the cyclic group Z₃, a reset bit); at each frame the bit moves by a 2 × 2 Markov matrix
  (2 parameters), then the phase advances by a group element drawn from a distribution over Z₃ that depends on the new
  bit (2 × 2 = 4); free emissions, each hidden state with its own categorical distribution over the three
  observed states, two free numbers each (6 × 2 = 12); initial distribution (5). *Unconstrained*:
  four hidden states, full transitions (4 × 3 = 12), categorical emissions as above (4 × 2 = 8), initial (3). Matching parameters, not
  states, is what makes the comparison fair: an unconstrained six-state model contains the cascade, so on enough data it
  could never lose to it, and a test against it could only refute; it is fitted and reported, not tested. Z₃ and the
  counts are fixed here, before the data are read. Held-out
  log-likelihood per frame on recordings split 50/50 by a seeded draw.
- **Baselines and controls**: the unconstrained model; *positive control*, sequences of block 1's total length
  generated from a
  cascade model with parameters fixed at preparation (each of the six states visited, the phase's group element not
  degenerate), on which the cascade must win (interval wholly above zero), or the fit cannot see a cascade and the lens
  stops - it should, since a four-state model cannot in general reproduce a six-state process, but this is to be shown
  on the control, not assumed; *negative control*, sequences from a random 6-state hidden Markov model, on which the
  cascade's advantage is reported.
- **Refuted if**: (automata) the cascade's held-out log-likelihood per frame minus the unconstrained model's has an
  interval wholly at or below zero; passed if wholly above zero.
- **The other lenses.** *Graphs*: a Program wired by the connectome against one wired by a degree-preserving rewiring is
  [C1-C12.md § C4](C1-C12.md#c4-the-connectome-as-a-mask---or-not)'s contrast; the cycle and motif counts are reported
  there, not tested twice. Whether the connectome's motifs are known to differ from degree-preserving nulls is a
  literature question, searched at preparation, since the answer may already be published. *Knots and braids*: the
  knot invariant needs a closed curve, and the body's path through the space of shapes is never exactly closed; the
  closure rule (a straight segment from end to start) and the three-dimensional projection (the first three eigenworm
  amplitudes) are fixed here, and the knot type of each closed turn is reported, with no test, since a noisy curve's
  knot
  type can change with the closure. A braid test needs three rhythms measured from the recordings; if fewer than three
  can be named at preparation, the braid lens has no test beyond a phase measure, and the plan says so in the report.
- **Statistics**: per recording, the difference in held-out log-likelihood per frame; bootstrap over held-out
  recordings, one-sided, alpha 0.05.
- **Seeds and repetitions**: the split by seed 3001; the 20 random starts by seeds 3101 to 3120; block 1's recordings.
  Repeated on block 2 once it is fetched, reported.
- **Switch**: none in a brain - a model of the worm's data. A Program that adopts a cascade gets `cascade = off`,
  replacing it with the unconstrained automaton of the same size.
- **Cost**: an evaluation tool's: EM on six states over block 1's frames, seconds per start.
- **Waits on**: nothing for the automata lens (block 1's states exist); the graph lens waits on C4; knots on the frozen
  benchmark's posture features.
- **Leads**: [Krohn and Rhodes 1965](https://doi.org/10.1090/S0002-9947-1965-0188316-1) (*Trans. AMS* 116, 450-464),
  found, not read; [White et al. 1986](https://doi.org/10.1098/rstb.1986.0056), found;
  [Stephens et al. 2008](https://doi.org/10.1371/journal.pcbi.1000028), found (read earlier for the lab's posture
  measures, not re-read tonight); [Birman 1974](https://doi.org/10.1515/9781400881420), found, not read.

## F15. Rhythm and direction twisted together, as in the Hopf fibration

- **Hypothesis** (*a hunch*): a creature's state held on the three-sphere, read out through the Hopf fibration, ties a
  direction to the phase of the body wave, so that steering round a closed loop shifts the rhythm by an amount the
  geometry fixes.
- **The mathematics, stated correctly** (from knowledge; checked numerically in the module's tests before any data are
  read). S³ = {(z₁, z₂) ∈ C² : |z₁|² + |z₂|² = 1}; the Hopf map sends (z₁, z₂) to (2 z₁ z̄₂, |z₁|² - |z₂|²), a point of
  S² in C × R; its fibres are the circles (e^(iφ) z₁, e^(iφ) z₂). S³ is not S² × S¹: the first is simply connected,
  the second has fundamental group Z. The normalised states of a two-level quantum system are S³, and their Bloch
  points are the Hopf image, as the hunch says. Transporting a state round a closed loop on S² by the bundle's natural
  connection shifts its phase by half the solid angle the loop encloses (Berry's phase for a spin one-half; Berry 1984
  found, not read). The sign depends on the loop's orientation; it is fixed by the module's test, computed for a small
  loop of known orientation, before any worm data are read.
- **A flaw in the hunch's worm test.** The worm's heading on the plane is one angle, a point of a circle, not of S². A
  closed turn on the plane is a loop round the equator, which encloses half the sphere whatever the turn's shape, so a
  holonomy read from the heading alone is a fixed π per full turn and depends on no "area the heading's path encloses".
  The test has content only if S² carries a second coordinate. **The worm test needs a redesign, and is suspended.**
  A first choice of latitude, the worm's signed path curvature κ, failed on review: with latitude built from κ, the
  signed solid angle is Ω = Δψ + ∫ sin(λ(κ)) κ v dt, nearly a linear function of Δψ and of K = ∫κ² dt whenever speed
  varies little within a turn, so the mechanical term K that must be controlled for absorbs the twist (the verifier of
  [#226](https://github.com/ai-quokka-wannabe/iso-lab/pull/226), on 300 synthetic turns, found Ω - Δψ regressed on
  [1, Δψ, K] with R² 0.990, a variance inflation near 100), and the positive control could fail with the twist present.
  The redesign must choose a latitude not built from κ (the body wave's amplitude, or the head swing's, are candidates)
  and must pass a stopping rule fixed here before any worm data are read: on the synthetic turns, the variance inflation
  factor of Ω against the product model's terms must be below 10, or the latitude is rejected. Ω is *signed* by the
  loop's orientation (positive for a loop anticlockwise seen from outside the sphere, the convention under which the
  module's test fixes the holonomy's sign), and taken on the side containing the south pole. The method below is kept
  as the design to be mended, not a plan to run.
- **Question**: (worm) after a turn, does the body wave's phase shift follow half the solid angle that the turn's loop
  encloses on this sphere, beyond what the net change of heading explains?
- **Method**: on block 1, each turn whose heading returns within 0.2 rad of its start, or changes by a full ±2π, is a
  closed loop; where the curvature at its end differs from its start, the loop is closed on S² by the shorter
  great-circle arc, a rule fixed here. The body-wave phase is atan2 of the second and first eigenworm amplitudes;
  its shift Δφ is the observed
  phase change over the turn minus the change expected from the recording's median undulation frequency over the turn's
  duration. Two linear models of Δφ, fitted over turns: *product*, Δφ = a + b·Δψ + e·K (net heading change Δψ, and
  K, the turn's integral of squared curvature over time, a plain mechanical coupling: since the sphere's latitude is
  curvature, a worm whose undulation merely slows while it bends would otherwise make c non-zero with no twist at all);
  *twisted*, the same plus c·Ω, where Ω is the loop's enclosed solid angle on S² with the orientation fixed above. A
  loop round the pole encloses Ω or Ω - 4π depending on the side, which changes -Ω/2 by 2π; so Δφ and the models are
  compared modulo 2π, the residuals wrapped to (-π, π] and the fit made by least squares on the wrapped residuals,
  Ω taken on the side that contains the south pole (a rule fixed here).
- **Baselines and controls**: the product model; *positive control*, synthetic turns generated with Δφ = -Ω/2 plus
  Gaussian noise at the worm's residual scale, on which the fit must return c's interval containing -1/2 and excluding
  zero, or the measure cannot see the twist; *negative control*, the worm's Δφ shuffled across turns, on which c's
  interval must contain zero.
- **Refuted if**, the two refuting tests corrected (alpha 0.025 each): (a) the interval of c contains zero - the twist
  explains nothing beyond the heading - passed if it excludes zero and has the sign of the geometric prediction; (b)
  the interval of c excludes -1/2 (the amount the geometry fixes, with the sign fixed by the module's test); passed if
  it lies wholly within [-0.75, -0.25] (an equivalence band fixed here), so that a wide interval cannot pass. A c of
  the right sign but another size is reported as a coupling, not as the
  Hopf geometry. And for a Program: the module on S³ against the untwisted product (an angle and a separate phase)
  at the same number of state variables, both fitted to the benchmark; refuted if the twisted Program's distance minus
  the product's has an interval wholly at or above zero, passed if wholly below. That test waits on (a) passing.
- **Statistics**: c by bootstrap over recordings (turns resampled within recording), two-sided 97.5% intervals, the
  level corrected for the two tests; the Program test by bootstrap over seeds, one-sided.
- **Seeds and repetitions**: block 1's recordings; synthetic controls by seeds 4001 to 4020; 20 seeds per Program.
- **Switch**: `twist = off` replaces the bundle with the product S² × S¹ in the Program, everything else equal.
- **Cost**: four numbers of state and a few dozen multiply-adds per tick for the module; an evaluation tool's for the
  worm test.
- **Waits on**: the redesign above for (a) and (b), then block 1's posture and heading; the Program test on a Program and the
  frozen benchmark.
- **Leads**: [Hopf 1931](https://doi.org/10.1007/BF01457962) (*Math. Ann.* 104, 637-665), found, not read;
  [Urbantke 2003](https://doi.org/10.1016/S0393-0440(02)00121-3) (*J. Geom. Phys.* 46, 125-150), found, not read;
  [Berry 1984](https://doi.org/10.1098/rspa.1984.0023) (*Proc. R. Soc. A* 392, 45-57), found, not read.

## F16. Harmonic analysis, and the Kakeya needle in a worm's turn

- **Hypothesis** (*a hunch*): the windowed uncertainty bound sets the pace at which a worm can switch rhythms, and an
  omega turn comes close to the least area in which a body of the worm's size can turn round.
- **The mathematics, stated correctly.** *Uncertainty* (Gabor's relation, from knowledge, cited from a text at
  preparation): for a window g with standard deviations σ_t of |g|² in time and σ_f of |ĝ|² in frequency,
  σ_t σ_f ≥ 1/(4π), with frequency f in cycles per unit time and the convention
  ĝ(f) = ∫ g(t) e^(-2πift) dt (in angular frequency the bound is 1/2), with equality for a Gaussian. It bounds how sharply a windowed estimate can resolve frequency, as
  the hunch says. *Kakeya*: Besicovitch 1928 (found, not read) showed that a unit segment can be turned round in a plane
  set of arbitrarily small area; among *convex* sets the least area is the equilateral triangle of height one, area
  1/√3 ≈ 0.577 (Pál 1921, found, not read; the number from `python3 -c "print(1/3**0.5)"`). Davies 1971 (found, not
  read) is the paper the hunch credits with the plane case of the Kakeya conjecture. Wang and Zahl's abstract (read)
  states a proof that every Kakeya set in R³ has Minkowski and Hausdorff dimension 3; it is a preprint, and whether it
  has been refereed was not checked.
- **Two flaws in the hunch's tests.** First, the uncertainty bound limits *estimating* a frequency from a window, not
  *changing* one's own: a motor rhythm can switch with no estimate at all, so the time a worm takes to switch
  undulation frequency has no mechanism tying it to the bound, and the hunch's rhythm clause has no testable content in
  that form. Its testable form would be a decision that depends on telling two *sensed* rhythms apart, and no such worm
  assay is known to the lab. Second, Kakeya's problem is about a *rigid* segment moved by translation and rotation; a
  worm is flexible, and bends round along itself rather than rotating as a rigid rod, so the rigid bounds do not
  constrain its omega turn. (Crawling backwards reverses its direction of travel but does not turn it round, and is not
  the comparison.) That a body
  of non-zero width needs positive area is trivial (it covers its own area L·w); the least area for a flexible body is
  not the Kakeya quantity and is not known to the lab. The reference recordings are on open plates, with no narrow space
  to turn in.
- **Question**: how large is the area an omega turn sweeps, in units of the body's length squared, against the rigid
  references - reported, not tested?
- **Method**: on block 1, each omega turn (the published rule's turns, as `features` gives them) has its swept area
  computed as the area of the union of the body's outlines over the turn, from skeletons widened by the recording's
  width feature, on a raster of 0.01 body lengths. Reported per turn as A/L², beside the references: 1/√3 (rigid
  needle, convex region), π/4 (a disc the needle's length across), and w/L (the body's own area).
- **Baselines and controls**: the same area for a 90° shallow turn, per radian of heading change, reported; *control*,
  a straight run of the same duration, whose swept area per radian is undefined and whose A/L² is reported to show the
  raster's floor.
- **Refuted if**: nothing is tested here; both clauses, as the hunch writes them, are ill-defined on the data the lab
  has, for the reasons above. A refutable form for turning waits on a confinement assay - worms in channels of stated
  width, on the Grid and in a public source - with the question "does the swept area fall with the channel's width
  faster than the rigid references allow?".
- **Statistics**: medians and 95% bootstrap intervals over recordings, reported.
- **Seeds and repetitions**: block 1; no seeds.
- **Switch**: none - a measure.
- **Cost**: an evaluation tool's: one raster union per turn.
- **Waits on**: the omega turns from `features` and a width per recording; the refutable form on a confinement assay
  and a source with worms in channels.
- **Leads**: Kakeya 1917, not found (no DOI; *Tôhoku Science Reports* is the hunch's attribution, unverified);
  [Pál 1921](https://doi.org/10.1007/BF01458387) (*Math. Ann.* 83, 311-319), found, not read;
  [Besicovitch 1928](https://doi.org/10.1007/BF01171101) (*Math. Z.* 27, 312-320), found, not read;
  [Davies 1971](https://doi.org/10.1017/S0305004100046867) (*Math. Proc. Camb. Phil. Soc.* 69, 417-421), found, not
  read; [Wang and Zahl 2025](https://arxiv.org/abs/2502.17655), abstract read;
  [Stephens et al. 2008](https://doi.org/10.1371/journal.pcbi.1000028), found.

## F17. Metaphysics, kept for its testable parts

- **Hypothesis** (*a hunch*): five ideas from philosophy, each kept for a part a run can refute. The philosophies
  themselves have no testable content, and nothing here tests Whitehead, Spinoza, Leibniz, Bergson or a theory of
  consciousness: each name labels a contrast between two brains, and the contrast is all that is tested.
- **Mind as process.** *Contrast*: a recurrent Program whose only state is its units' activity (no weight changes in
  life) against the same Program with a plastic store; "numbers held" counts every stored number - fixed weights,
  plastic weights and activities alike - and the activity-only Program is given extra units, with their own fixed
  weights, until its count equals the other's; both Programs' size (units, weights, numbers held) and compute per
  simulated second are reported beside the result, as *Lean brains* asks. *Refuted if* the activity-only Program's benchmark distance minus the other's has an
  interval wholly at or above zero; passed if wholly below. Habituation ([E1-E5.md §
  E1](E1-E5.md#e1-habituation-is-ten-properties-not-one-decrement))
  is where the two should part, and its measures are reported beside. Every recurrent network stores state in its
  activity, so the contrast is "activity only" against "activity and weights", not "no memory" against "memory".
- **Striving to persist.** A single objective that is a weighted sum of separate drives *is* a set of separate drives,
  combined additively; the two are the same brain. The contrast with content is the rule of combination: *additive*
  (one scalar objective) against *arbitrated* (one drive wins each cycle, as
  [C1-C12.md § C10](C1-C12.md#c10-many-proposals-one-commitment-per-cycle) plans), at the same drives and gains.
  *Refuted if* the additive Program's distance minus the arbitrated one's has an interval wholly at or above zero;
  passed if wholly below.
- **Each creature mirrors the world from where it stands.** Planned as
  [E16-E20.md § E17](E16-E20.md#e17-maps-at-several-scales), whose review found that the contrast is range and
  reset, not
  frame; not planned twice.
- **Lived time is not clock time.** Time constants that stretch with arousal, judged on the worm's pace, is
  [C13-C24.md § C13](C13-C24.md#c13-vigour-from-the-average-reward-rate-one-global-slowing-factor)'s one global slowing
  factor; not planned twice.
- **Integrated information.** The number of ways to cut n units into two non-empty parts is 2^(n-1) - 1, about
  4 × 10⁹⁰ at n = 302 (`python3 -c "print(2**301)"`), so any measure that searches over cuts needs a named
  approximation, chosen at preparation from a source read then. *Question*: does the approximated measure carry
  information about behaviour beyond a plain control? *Method*: over a population of 40 Programs drawn from one family
  fixed here - the activity-only Program of the first contrast at 32, 64, 128 and 302 units, ten seeds each, with weights
  drawn by the seed and scaled to a spectral radius drawn uniformly in [0.5, 1.5], so that their benchmark distances
  differ - the Spearman correlation of the measure with the distance, against the same correlation
  for the entropy of the units' activity. *Refuted if* the measure's absolute correlation minus the entropy's has an
  interval wholly at or below zero; passed if wholly above. The direction of the measure's own correlation is not
  predicted, so the absolute value is compared, fixed here. Nothing about consciousness follows either way.
- **Statistics**: the two Program contrasts paired by seed, bootstrap over seeds, one-sided; the correlation by
  bootstrap over Programs. Three refuting tests here (process, persistence, integration), alpha 0.05/3 each.
- **Seeds and repetitions**: 20 per Program, the default; the population of 40 Programs drawn by seeds 5001 to 5040.
- **Switch**: `plastic = off` (process), `arbitration = additive` (persistence); none for the measure.
- **Cost**: the Programs are matched in numbers held; the measure is an evaluation tool's, its cost reported with the
  approximation chosen.
- **Waits on**: Programs, the frozen benchmark, and for the measure a population of Programs.
- **Leads**: [Tononi 2004](https://doi.org/10.1186/1471-2202-5-42) (*BMC Neurosci.* 5), found, not read; Whitehead
  1929, Spinoza 1677, Leibniz 1714 and Bergson 1889, not looked up (books, used as labels only).
