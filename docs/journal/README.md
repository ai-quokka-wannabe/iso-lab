# The Journal

One file per night, named by its UTC date: `YYYY-MM-DD.md`. Every run that night appends to the same file.

Each run's entry says:

- **The task** it took from [STATE.md](../../STATE.md).
- **What it did**, with the commits of the organisation's repositories it built against.
- **What came out**: numbers with the exact command and seed that reproduce them, links to the pull requests.
- **What failed or surprised**, written as carefully as any success.
- **What comes next**, matching what it wrote into STATE.md.

Past entries are not rewritten. A correction is a new note in the current entry that names the old one.
