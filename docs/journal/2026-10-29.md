# 2026-10-29

## The Linter's Vulnerable Dependencies, Overridden

Written by iso-lab's night staff, an AI agent; not by the maintainer.

A housekeeping pass at the maintainer's request. `npm audit` on `main` (`4559f90`) reported five vulnerabilities, two
low and three high, all in the markdown linter's own dependencies and all reached through `markdownlint-cli2` 0.24.0
-> `markdownlint` 0.42.0:

- `katex` 0.16.47, through `micromark-extension-math` (prototype pollution,
  [GHSA-238p-pmpm-9mq7](https://github.com/advisories/GHSA-238p-pmpm-9mq7), affected 0.11.0 to 0.18.1);
- `re2js` 2.8.6, which `markdownlint` 0.42.0 pins exactly (quadratic-time matching with lookbehind,
  [GHSA-gg6h-894w-4m9c](https://github.com/advisories/GHSA-gg6h-894w-4m9c), affected 2.2.0 to 2.8.6).

`markdownlint-cli2` 0.24.0 is the latest release, so no linter bump reaches either fix; `npm audit fix --force` would
go back to 0.23.3. The three world repositories met the first one the same way on 2026-10-27, with an npm override
of `katex` to 0.18.2 (link `49a7d8f`, master-control `2e115af`, tron-grid-lite `a596fb8`). The lab copies that
override and adds one for `re2js` to 2.8.7, the first release outside the affected range. Both are MIT-licensed and
dev-only: they run in CI's lint step and ship in nothing.

- **Checked**, with Node 22.22.0: `npm ls katex re2js` shows 0.18.2 and 2.8.7, both marked overridden; `npm audit`
  finds 0 vulnerabilities; `npx markdownlint-cli2 "**/*.md"` lints 40 files with 0 issues (39 on `main`; the fortieth is this entry).
- **Red first**: the linter with the overridden dependencies still fails a file written to break a rule (a `*` list
  item, reported as MD004), so the override has not silenced it.
- The new `re2js` declares Node 20 or later; CI installs `lts/*`.
