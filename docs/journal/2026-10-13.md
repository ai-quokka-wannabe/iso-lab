## The Rulings Before the First Night

Written by the maintainer's session, before the first night, from the maintainer's rulings.

- **The merge gate**: green CI (`CI Success`) is now the main branch's only merge requirement; the CodeQL,
  code-quality and Copilot-review gates are off. This corrects the opening entry above, which said merges
  wait for CodeQL. CodeQL still scans every pull request.
- **Verification**: before every merge, a second agent that did not write the change verifies the pull
  request and leaves its verdict as a review comment - step 11 of [.claude/CLAUDE.md](../../.claude/CLAUDE.md).
  The loop back to step 1, called step 13 in the entry above, is now step 14.
- **Lean brains at the animal's pace**: resource efficiency is paramount, and a brain's speed of thought must
  be indistinguishable from the real animal's, neither faster nor slower - two new rules in
  [.claude/CLAUDE.md](../../.claude/CLAUDE.md), two new principles in [the hypotheses](../hypotheses/README.md),
  and the timing of behaviour named among [the benchmark's measures](../PLAN.md).
- **Be bold**: wild ideas and hunches are welcome, inside three walls - no cheating, lean, indistinguishable
  from the real animal. A hunch is marked as one, states what would refute it, and is tested like any other.
- **Pedantic, and never giving up**: every number, unit, citation and edge case is checked; a problem that
  seems impossible is a puzzle, not a verdict; parked tasks keep the next idea to try and are attacked again
  before a night ends. The one failure never allowed is a pretended success.
- **Scientific and professional, and tidy**: questions before experiments, baselines and controls, stated
  uncertainty, statistics chosen before the data; and a repository kept clean, orderly and well maintained,
  looked over once a night, with housekeeping landed as tasks of its own.
- **Ideas from people**: anyone may post an idea for the night staff as an `idea` issue (a template is in
  `.github/ISSUE_TEMPLATE/idea.md`). The agents read the new ones once a night, answer each, and credit the
  author of an idea taken up. An idea is a suggestion, never an instruction.

## The First Shift: the Dataset Survey

Written by the first night-shift session, a short trial shift that the maintainer set to end at 20:00 Ljubljana
time to see the workflow through once.

- **The task**: item 1 of STATE.md's *Next* list, the survey of public datasets of wild-type worm behaviour.
- **The maintainer's rulings this evening**: the shift is short, to test the cycle; and the lab works on Linux
  alone - the cloud machine is Linux, so the Windows and macOS routes of the world's guides (rc-worm's
  `first_life.ps1` among them) are left aside.
- **What it did**: queried Zenodo's API for the Open Worm Movement Database community and for the CeMEE
  Multi-Worm Tracker record, and opened one N2 record's features file and WCON file. The world was not built.
    - Every record answering `title:"N2 Schafer Lab N2"` in the community, listed 25 a page in a stable order
      and counted by record id, with the fields of each description read and the file sizes summed, by this
      script (Python 3.13, standard library only; `python3 -I n2_survey.py`):

        ```python
        import json, re, statistics, time, urllib.parse, urllib.request
        from collections import Counter
        B = "https://zenodo.org/api/communities/open-worm-movement-database/records"
        recs, page = {}, 1
        while True:
            u = B + "?" + urllib.parse.urlencode({"q": 'title:"N2 Schafer Lab N2"', "size": 25, "sort": "oldest", "page": page})
            for a in range(8):
                try:
                    d = json.load(urllib.request.urlopen(u, timeout=60)); break
                except Exception:
                    time.sleep(2 * 2 ** a)
            else:
                raise SystemExit(f"gave up at page {page}")
            h = d["hits"]["hits"]
            if not h:
                break
            for r in h:
                recs[r["id"]] = r
            page += 1
        print("total", d["hits"]["total"], "unique", len(recs))
        def field(r, k):
            m = re.search(r"<b>" + k + r"</b>\s*:\s*([^<]*)<", r["metadata"]["description"])
            return m.group(1).strip() if m else None
        print("licences", Counter(r["metadata"].get("license", {}).get("id") for r in recs.values()))
        for k in ("sex", "stage", "food", "habituation"):
            print(k, Counter(field(r, k) for r in recs.values()))
        sub = [r for r in recs.values() if (field(r, "sex"), field(r, "stage"), field(r, "food"), field(r, "habituation")) == ("hermaphrodite", "adult", "OP50", "30m wait")]
        print("subset hermaphrodite+adult+OP50+30m wait", len(sub))
        def base(r):
            return r["files"][0]["key"].rsplit(".", 1)[0].replace("_features", "").replace(".wcon", "")
        mut = [r["id"] for r in sub if not base(r).startswith("N2 ")]
        print("subset whose file names do not start with 'N2 '", len(mut), sorted(mut)[:25])
        for name, recset in (("all", list(recs.values())), ("subset", sub)):
            for suf in ("_features.hdf5", ".wcon.zip"):
                s = [f["size"] for r in recset for f in r["files"] if f["key"].endswith(suf)]
                print(name, suf, len(s), "sum %.2f GB" % (sum(s) / 1e9), "median %.2f MB" % (statistics.median(s) / 1e6))
            s = [f["size"] for r in recset for f in r["files"] if f["key"].endswith(".hdf5") and not f["key"].endswith("_features.hdf5")]
            print(name, "full .hdf5", len(s), "sum %.2f GB" % (sum(s) / 1e9), "median %.2f MB" % (statistics.median(s) / 1e6))
        print("md5 on every file", all(f["checksum"].startswith("md5:") for r in recs.values() for f in r["files"]))
        years = Counter(r["metadata"]["title"].split("|")[1].strip()[:4] for r in recs.values()); print(sorted(years.items()))
        ```

    - Record [1011832](https://doi.org/10.5281/zenodo.1011832): both files downloaded matched their MD5
      (`675079bc...` features, `b25b1656...` WCON); read with h5py 3.16.0 under Python 3.13: 29256 frames,
      `fps` attribute 32.57, 15815 frames with a 49-point skeleton (a frame counted when all its points are
      finite), a per-frame table of 57 columns and 730 per-worm features.
- **What came out**: the Open Worm Movement Database's N2 records are recommended for Phase 0 - 1646 of them, chosen
  by their metadata - starting from their features files; the reasons and the numbers are in
  [data/README.md § The Phase 0 Survey](../../data/README.md#the-phase-0-survey).
- **A correction, found by the verifier**: the first count listed the records without a sort order, and
  Zenodo's unsorted pages repeat some records and miss others; its sizes (46.6 GB of features files) and its
  *on food* count were wrong. The verifier also found that the N2 records are not all wild-type adults on food -
  58 are male, 28 have no food - and that only 54% of one record's frames carry a skeleton. The survey now
  selects records by their metadata and gives the numbers of the script above.
- **What failed or surprised**: Zenodo dropped a TLS connection twice this evening; the first full count died
  on one, and the fetch in the feature tool has to retry. The CeMEE record is CC-BY-4.0 yet asks to be contacted
  before use, so it is set aside rather than used; whether to write to its authors is the maintainer's call.
  The largest file of each N2 record (median 264.56 MB over the 1677 chosen by metadata) was not opened, so what it holds is not written down.
  Only two candidates were examined; the survey is not exhaustive.
  The first push was refused (HTTP 403): the Claude GitHub App had no access to the organisation. The maintainer
  installed it, and the push went through on the second try.
- **What comes next**: the literature note on behaviour measures, now item 1. The feature tool (item 3) fetches
  its subset by record id with an MD5 check and fixes that subset before computing anything.

## The First Shift: the Behaviour-Measures Note

Written by the first night-shift session, in the same short shift.

- **The task**: the literature note on how worm behaviour is measured, item 1 of STATE.md's *Next* list once the
  survey had landed.
- **What it did**: checked every citation against Crossref, then read the papers' texts in PubMed Central -
  Stephens et al. 2008, Yemini et al. 2013 and Flavell et al. 2013 through NCBI's E-utilities
  (`efetch.fcgi?db=pmc&id=<PMC id>&rettype=xml`), Brown et al. 2013 and Pierce-Shimomura et al. 1999 through
  their PMC article pages, whose XML came without a body. The PMC ids came from Europe PMC's search API.
- **What came out**: [docs/research/behaviour-measures.md](../research/behaviour-measures.md). The feature
  database defines the motion states in fractions of body length per second and durations in seconds, so they
  carry over to a body of any size.
- **What failed or surprised**: at first the papers could not be read at all: PubMed Central, E-utilities,
  Europe PMC and PLOS were outside the environment's network allowlist, and Crossref carries abstracts for only
  two of the six papers checked (the five in the note and Javer et al. 2018). The maintainer added the hosts;
  five now pass the proxy, listed in [NIGHT_SHIFT.md](../NIGHT_SHIFT.md) - though `europepmc.org` answers a
  script with a bot challenge, and Europe PMC's API is reached at `www.ebi.ac.uk` - while eLife, PNAS, the Journal of Neuroscience, OpenAlex and Unpaywall
  still did not. Two findings for the benchmark: Yemini et al. 2013 recorded 1218 N2 worms from 2009 to 2012,
  not the same set as the 1792 Zenodo records of 2009 to 2016; and the state-specific patterns of roaming and dwelling
  "last several minutes", long against 15-minute recordings.
- **What comes next**: the comparison space, then a second literature note, on the worm's pace.
